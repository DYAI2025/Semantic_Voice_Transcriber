# 🎤 SVT Local - Therapie Transkription

**Einfache Software für Therapeuten - Lokal, sicher, DSGVO-konform.**

---

## Was kann SVT Local?

| Feature | Beschreibung |
|---------|-------------|
| 🎤 **Transkription** | Sprachaufnahmen in Text umwandeln |
| 👥 **Sprecher-Erkennung** | automatisch Therapeut vs Patient erkennen |
| 🧠 **Analyse** | Wichtige Inhalte zusammenfassen |
| 📄 **Export** | PDF, DOCX, JSON Dateien erstellen |

---

## Installation (Windows)

### Schritt 1: Python installieren
1. https://python.org/downloads/ öffnen
2. "Download Python 3.11" klicken
3. Installieren (✓ "Add Python to PATH" aktivieren!)

### Schritt 2: SVT Local installieren
1. Diese Datei entpacken
2. `install_svt.bat` als Administrator ausführen
3. Warten bis alles installiert ist

### Schritt 3: Starten
1. `svt_local_gui.py` ausführen
2. Oder: Desktop Verknüpfung erstellen

---

## Verwendung

### Transkription erstellen

```
1. "Durchsuchen..." klicken
2. Audio-Datei auswählen (MP3, WAV, M4A)
3. "Transkription starten" klicken
4. Warten (abhängig von Dateilänge)
5. Ergebnisse ansehen und exportieren
```

### Export-Formate

| Format | Verwendung |
|--------|-----------|
| PDF | Für Akten, ausdrucken |
| DOCX | Weiterbearbeiten in Word |
| JSON | Für andere Software |
