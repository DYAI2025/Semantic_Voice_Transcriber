# Pilot Rollout Plan

**Last Updated:** 2025-11-19 | **Verified against commit:** 75fdfbbc

1. **Target Group**: 5–10 non-technical therapists.
2. **Assets**: Windows Lite installer + quick start PDF.
3. **Steps**:
   - Provide download link + short survey.
   - Ask participants to install, process a sample audio, and send feedback.
4. **Feedback Capture**: Form with sections Installation, Health Check, Transcription, Dashboard, Overall.
5. **Success Criteria**: >=80% complete flow without manual CLI intervention; all blocking issues ticketed.
