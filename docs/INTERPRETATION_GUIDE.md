# SVT Ergebnisse interpretieren

## Ein Leitfaden für Therapeuten

---

## Die Analyse verstehen

### Transkription

Die Basis ist die **wörtliche Transkription** der Sitzung. Achten Sie auf:

- **Wörtliche Rede:** Was gesagt wurde
- **Kontext:** Wann etwas gesagt wurde
- **Sprecherzuordnung:** Wer was gesagt hat

### Prosodie (Wie es gesagt wurde)

Die Prosodie-Analyse liefert objektive Daten zur Sprechweise:

#### Tempo

| Wert | Interpretation |
|------|----------------|
| < 90 Wörter/Min | Langsam, depressiv, überlegend |
| 90-120 Wörter/Min | Normal |
| > 130 Wörter/Min | Schnell, erregt, ängstlich |

**Klinischer Hinweis:** Tempo-Veränderungen innerhalb einer Sitzung sind oft aussagekräftiger als absolute Werte.

#### Tonhöhe (Pitch)

| Muster | Interpretation |
|--------|----------------|
| Ansteigend | Frage, Unsicherheit, Erregung |
| Abfallend | Aussage, Trauer, Resignation |
| Variabel | Emotionale Erregung |
| Flach | Neutral, kontrolliert |

#### Pausen

| Typ | Dauer | Interpretation |
|-----|-------|----------------|
| Kurze Pause | < 1 Sek | Natürliches Sprechen |
| Mittlere Pause | 1-3 Sek | Überlegen |
| Lange Pause | > 3 Sek | Widerstand, emotionale Belastung |

**Klinischer Hinweis:** Lange Pausen nach therapeutischen Fragen können Widerstand anzeigen.

#### Energie/Lautstärke

| Muster | Interpretation |
|--------|----------------|
| Leise | Scham, Unsicherheit, Trauer |
| Normal | Kontrolliert |
| Laut | Erregung, Wut, Überforderung |

## ATO-Marker interpretieren

### Abwehrmechanismen

#### [DEN] Denial (Verleugnung)
```
Patient: "Nein, das ist kein Problem. [DEN]
         Ich habe überhaupt keine Angst vor der Untersuchung."
```
→ Patient leugnet offensichtliche Ängste

#### [PROJ] Projection (Projektion)
```
Patient: "Meine Kollegen sind immer so aggressiv zu mir. [PROJ]
         Die können mich nicht leiden."
```
→ Mögliche Projektion eigener Aggressionen

#### [RAT] Rationalization (Rationalisierung)
```
Patient: "Es ist gut, dass es so gelaufen ist. [RAT]
         Ich hätte sowieso keine Zeit gehabt."
```
→ Logische Erklärung für emotionale Situationen

### Widerstand

#### [HED] Hedge (Unsicherheitsmarker)
```
Patient: "Ich weiß nicht, ob ich das... [HED]
         also... ich meine... [HED]
         es war vielleicht doch wichtig."
```
→ Zögern, Unsicherheit, Vermeidung

#### [SIL] Silence (Schweigen)
```
Therapeut: "Erzählen Sie mir mehr über Ihre Kindheit."
[Patient schweigt 5 Sekunden]
Patient: "Da gibt es nichts zu erzählen."
```
→ Deutlicher Widerstand

#### [TC] Topic Change (Themenwechsel)
```
Patient: "Ja, das mit meinem Vater... [TC]
         Übrigens, wie lange dauert die Sitzung noch?"
```
→ Abrupter Themenwechsel zur Vermeidung

### Emotionale Marker

#### [FEA] Angst
```
Patient: "Ich habe... [HED]... ich habe wirklich Angst, [FEA]
         dass ich das nicht schaffe."
```
→ Direkte oder indirekte Angstäußerung

#### [SAD] Traurigkeit
```
Patient: "Es ist einfach... [SIL]... es ist einfach schwer. [SAD]"
```
→ Traurigkeit, depressiver Affekt

#### [INS] Insight (Erkenntnis)
```
Patient: "Und dann habe ich gemerkt... [META]...
         ich wiederhole das gleiche Muster! [INS]"
```
→ Erkenntnismoment, Selbstreflexion

## Wendepunkte erkennen

### Emotional Shift

**Zeichen:**
- Plötzliche Stimmungsveränderung
- Wechsel in der Prosodie
- Emotionale Äußerungen

**Beispiel:**
```
Patient: "Es war immer alles schwierig..." [SAD, tiefe Stimme]
         [kurze Pause]
         "Aber jetzt... [EMO, Stimme wird lebhafter]
         jetzt sehe ich das anders!" [JOY, höhere Stimme]
```

### Resistance Breakthrough

**Zeichen:**
- Zunächst Widerstand
- Dann plötzliche Öffnung
- Durchbruch einer Abwehr

**Beispiel:**
```
Therapeut: "Was war damals passiert?"
Patient: "Ich will nicht darüber reden." [AVO, HED]
         [lange Pause]
         "Na gut... es war so..." [Widerstand bricht]
```

### Insight Moment

**Zeichen:**
- Selbstreflexion
- Neue Einsicht
- "Aha"-Momente

**Beispiel:**
```
Patient: "Ich bin immer weggegangen. [META]
         Immer wenn es ernst wurde. [INS]
         Das ist wie bei meinem Vater!" [korrelative Erkenntnis]
```

## Praktische Anwendung

### Sitzungsvorbereitung

1. Vorherige Transkripte laden
2. Memory-Profil prüfen
3. Offene Punkte aus vorherigen Sitzungen notieren

### Nachsitzung

1. Transkription erstellen
2. ATO-Marker und Wendepunkte prüfen
3. Für nächste Sitzung planen:
   - Welche Themen blieben offen?
   - Wo gab es Widerstand?
   - Gab es Erkenntnismomente?

### Dokumentation

- Wendepunkte für Verlaufsdokumentation nutzen
- ATO-Marker als klinische Notizen
- Prosodie-Daten für Forschung/Supervision

---

## Warnhinweise

⚠️ **Wichtige Hinweise:**

1. **Keine Diagnose:** SVT liefert Hinweise, keine klinischen Diagnosen
2. **Menschliches Urteil:** Ihre klinische Einschätzung bleibt zentral
3. **Kontext beachten:** Marker immer im Sitzungskontext interpretieren
4. **Kulturelle Faktoren:** Prosodie variiert kulturell
5. **Individuell bewerten:** Nicht jeder Marker bedeutet dasselbe bei jedem Patienten

## Beispiele aus der Praxis

### Fall 1: Widerstand erkennen

```
Transkript-Ausschnitt:
---
[T00:12:30] Therapeut: Wie war Ihre Woche?
[T00:12:35] Patient: Gut. [kurze Antwort]
[T00:12:38] Therapeut: Erzählen Sie mir mehr.
[T00:12:40] Patient: Ähm... [HED] es war... [SIL] 
           wissen Sie, ich muss nochmal an den Termin denken. [AVO]
           [TC] Übrigens, haben Sie Urlaub geplant?
---

Analyse:
- "Gut" → Minimierung
- [HED] → Zögern
- [SIL] 2 Sek → Nachdenken/Widerstand
- [AVO] → Ausweichen
- [TC] → Themenwechsel

→ Deutlicher Widerstand gegenüber Thema
```

### Fall 2: Wendepunkt

```
Transkript-Ausschnitt:
---
[T00:35:15] Patient: Ich bin immer... [SIL]
           ich bin immer allein geblieben. [SAD]
           [META] Warum eigentlich?
           [INS] Weil ich Angst habe! [FEA]
           [EMO] Zum ersten Mal sage ich das laut!
---

Analyse:
- [SIL] → Sammlung
- [SAD] → Traurigkeit
- [META] → Selbstreflexion beginnt
- [INS] → Erkenntnismoment
- [FEA] → Angst wird bewusst
- [EMO] → Emotionaler Durchbruch

→ Therapeutischer Wendepunkt erreicht!
```

## Zusammenfassung

| Schritt | Aktion |
|---------|--------|
| 1. Transkription laden | Rohdaten ansehen |
| 2. Marker prüfen | ATO-Marker und Prosodie checken |
| 3. Wendepunkte identifizieren | Bedeutsame Momente finden |
| 4. Klinisch einordnen | Im Kontext bewerten |
| 5. Dokumentieren | Für Verlauf nutzen |

---

**Hinweis:** Dieser Leitfaden ersetzt keine klinische Ausbildung. Nutzen Sie SVT als Werkzeug zur Unterstützung Ihrer therapeutischen Arbeit.
